# 📚 BookShopLanding - Книжный мир 📚

## Что это за проект?
<b>Книжный мир</b> - это небольшой пет проект книжного онлайн магазина, в котором реализованы все базовые функции для данной предметной области, такие как:
* Управление основными ресурсами магазина - информацией об авторах, жанрах, книгах, филиалах, заказах и т.д.
* Авторизация и разграничение прав доступа - разделение на пользователей и администраторов, использование сессионной аутентификации
* Кэширование данных

## Что включено в проект?
<b>Книжный мир</b> разработан на основе <i>клиент-серверной архитектуры</i> и включает в себя:
* FastAPI приложение - классическое монолитное ASGI приложение, написанное на фреймворке FastAPI с применением стандартной трехслойной архитектуры: данные (repositories) -> сервисы (servicies) -> эндпойнты (routes)
* React приложение - клиентское приложение, предназначенное только для покупателей книжного магазина, написенное на React JS

В число внешних statement'ов, необходимых для развертывания включены:
* СУБД PostgreSQL - основная СУБД для приложения
* СУБД Redis - дополнительная БД для кэширования и аутентификации
* phpPgAdmin - приложение для администрирования СУБД - опционально

## Развертывание проекта
Для того, чтобы развернуть проект, в вашей системе должен быть установлен Docker. Процесс установки включает в себя:
* Клонирование текущего репозитория в локальную папку: git clone https://github.com/Lisiks/BookShopLanding.git .
* Изменение и настройка необходимых параметров конфигурации в .env файле (для тестового запуска можно оставить текущие настройки)
* Запуск compose приложения при помощи docker compose up --build -d
* Проверка работы приложения

### Проверка работы приложения
* localhost:8000/docs - страница в документацией по API приложения
* localhost:5173/ - главная страница клиентского react приложения
* localhost:8080/ - phpPgAdmin
